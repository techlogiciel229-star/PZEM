# RAJI — Maquettes Officielles (3 Plateformes)

Projet **RAJI (Réseau Africain des Jeunes Innovateurs)** — maquettes officielles réorganisées et reconstruites à partir du dernier export Stitch.

> **⚠️ Statut des maquettes :** les maquettes sont **susceptibles d'être modifiées**. Elles servent de référence de design pour le développement (frontend) et ne constituent pas une version définitive.

---

## 🗂️ Organisation du dossier

| Dossier | Contenu | État |
| :--- | :--- | :--- |
| **`android_mobile/`** | 68 maquettes Mobile (390 px) + captures + `index.html` + `README.md` | ✅ Reconstruit depuis export Stitch |
| **`tablette/`** | 50 maquettes Tablette (820 px) + captures + `index.html` + `README.md` | ✅ Reconstruit depuis export Stitch |
| **`pc_desktop/`** | 40 maquettes PC/Desktop (1440 px) + captures + `index.html` + `README.md` | ✅ Reconstruit depuis export Stitch |
| **`ancien_versions/`** | Versions précédentes archivées (anciens dossiers plateformes + export Stitch brut) | 📦 Archive |

Chaque dossier plateforme contient :
- `index.html` — galerie de présentation, cliquez sur une maquette pour l'ouvrir (même onglet)
- `captures/` — aperçus numérotés `NN_titre_id.png`
- `html/` — maquettes HTML numérotées `NN_titre_id.html`
- `README.md` — index trié selon le Cahier des charges
- `manifest.json` — source de données Stitch
