Protocole Modbus RTU

Les PZEM-004T v3.0 utilisent le standard de commandes Modbus 0x04 (Read Input Registers) avec des registres de 16 bits non signés.

0x0000 - Tension :0.1 V / LSB
0x0001 - Courant :0.001 A / LSB
0x0003 - Puissance :0.1 W / LSB
0x0005 - Énergie :1 Wh / LSB

Confirmer la remise à zéro de l'énergie (Reset kWh)

Commande Modbus 0x42 (Reset Energy Register)

Attention : Cette opération transmet une trame de commande spéciale qui réinitialise le registre d'accumulation matérielle du module PZEM-004T à 0.00 kWh.

L'historique télémétrique antérieur restera archivé dans InfluxDB / PostgreSQL, mais le compteur physique repartira instantanément de zéro pour les futures agrégations de puissance.
